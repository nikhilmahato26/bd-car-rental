## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm or yarn

### Installation

```bash
# Clone the repository via SSH
git clone git@github.com:nikhilmahato26/bd-car-rental.git

# Navigate to project directory
cd bd-car-rental

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
# Build production bundle
npm run build

# Preview build locally
npm run preview
```
